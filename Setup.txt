⚙️ Setup-Instructions (In a git bash)

📦 Requirements
--------------------------------------------
Node.js + npm
Python 3.10+
Git
--------------------------------------------

🖼 start frontend
--------------------------------------------
cd frontend
npm install
npm run dev
--------------------------------------------

🔧 Setup backend
--------------------------------------------
cd backend
python -m venv venv
venv/Scripts/activate          # Windows
# or: source venv/bin/activate  # macOS/Linux

pip install -r requirements.txt
uvicorn app.main:app --reload
--------------------------------------------
