⚙️ Setup-Anleitung

📦 Voraussetzungen
--------------------------------------------
Node.js + npm
Python 3.10+
Git
--------------------------------------------

🔧 Backend einrichten
--------------------------------------------
bash
Kopieren
Bearbeiten
cd backend
python -m venv venv
venv\Scripts\activate          # Windows
# oder: source venv/bin/activate  # macOS/Linux

pip install -r requirements.txt
uvicorn app.main:app --reload
--------------------------------------------

🖼 Frontend starten
--------------------------------------------
bash
Kopieren
Bearbeiten
cd frontend
npm install
npm run dev
--------------------------------------------
